# Звук Stage Shift

Исходные WAV повторяют структуру `/Game/SOUNDS`. Для замены положите свой файл на место исходника или выберите **Reimport With New File** на соответствующем Sound Wave в Unreal. Сохраните имя и путь ассета, чтобы все привязки продолжили работать.

- `Music` содержит зацикленные темы меню, хаба и спектакля. Громкость настраивается на акторе `Music ...` соответствующей карты.
- `UI` содержит звуки меню, выбора постановки и подтверждения вступления.
- `Character` содержит шаги по дереву, приземление и падение куклы.
- `Props` содержит подбор, отпускание, бросок и удар реквизита.
- `Stage` содержит рельсы, поворотную сцену и переключатель прожектора. В `Stage/Cues` лежат существующие стук, удар и скрип для звукового пульта.

Музыка использует стерео WAV. Пространственные эффекты используют моно WAV и общую настройку `Attenuation/ATT_Theatre`.
