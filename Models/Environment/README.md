# Библиотека окружения Stage Shift

Общие игровые меши, экземпляры материалов и карты лежат в `/Game/MODELS/Environment`. Каталог [Library.json](Library.json) содержит пути пакетов и их исходников для повторного импорта. Мебель, реквизит, костюмы, архитектура, освещение и оснастка разложены по одноимённым семействам.

`BackstageKit.blend` и `FrontOfHouseKit.blend` содержат общую геометрию закулисья и меню. Сборки локаций ссылаются на эти файлы через относительные пути. `Export` в каждом семействе хранит FBX и опубликованные карты. Редактируемые Painter-проекты остаются в папках соответствующих локаций.

## Кресло аудитории

`Auditorium/Auditorium.blend` содержит общую геометрию кресла. Сборка `CrimeAndPunishment/StageShift_AssetKit.blend` связывает сетку по относительному пути. Меш и материал, которые используют меню и постановка, находятся в `/Game/MODELS/Environment/Auditorium`.

`Auditorium/Export` содержит FBX и три опубликованные карты 512 × 512. В `Auditorium/PBR` лежат одобренные полноразмерные FlatHP-карты для повторной публикации. Исторический проект ткани остаётся в `CrimeAndPunishment/Theatre/Surfacing/Painter/Fabric`. Перед новым экспортом из Painter сверьте стек фильтров и результат с этими картами.

## Сценическая верёвка

`Rigging/TheatreRope.blend` содержит метровый сегмент с тремя прядями и деревянную рукоять. В Blender рукоять смещена для просмотра рядом с верёвкой. Готовые отдельные FBX в `Rigging/Export` используют локальные начала координат в центре каждого меша. Ось длины сегмента `Z`, номинальный диаметр 7,5 см. UV на боковой поверхности идут вдоль прядей, отдельные острова отведены торцам.

`Rigging/Painter/TheatreRope.spp` хранит два редактируемых набора. `Hemp Rope` и `Wood Russet` импортированы в сам проект. AO запечён для отдельных мешей без подложки. В `Rigging/PBR` для обоих наборов есть Base Color, Normal DirectX и ORM 2048 × 2048.

Меши `SM_TheatreRope_Segment` и `SM_TheatreRope_Grip` в `/Game/MODELS/Environment/Rigging` подключены в существующем `StageBackstageRope`. Рукоять использует исходные размеры 15 × 15 × 31 см. Сегменты масштабируются вдоль локальной Z под длину механизма. У визуальных мешей коллизия выключена. Поиск цели взаимодействия выполняет исходный `UseTarget`.

`Rigging/Export` содержит игровые карты 1024 × 1024 для шнура и 512 × 512 для рукояти. После редактирования `TheatreRope.spp` сохраните исходный набор в `Rigging/PBR`, обновите уменьшенные карты с теми же именами в `Rigging/Export` и реимпортируйте их в Unreal.
