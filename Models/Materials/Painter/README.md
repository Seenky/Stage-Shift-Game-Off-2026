# Stage Shift Painter Library

`Library.json` хранит источник, Texture Set и состав слоёв каждого SPSM. Начинайте с действующего SPP ближайшего игрового аналога. Готовый вид задаёт весь стек, включая его авторские слои, маски и фильтры. Правила сверки и рабочие примеры собраны в [руководстве по производству](../../../Docs/ProductionWorkflow.md#текстуры-и-материалы).

Импортируйте материалы Stage Shift из `Smart Materials` с назначением Smart Material и маски из `Smart Masks` с назначением Smart Mask. Для переносимого SPP выбирайте импорт в проект. Маску контакта на запечённом AO проверьте на открытой плоскости и на углублениях.

Используйте общую основу для дерева, бархата, коврового ворса, бумаги, картона, металла и кожи. Цветовые варианты дерева и сценической краски хранятся рядом. Трикотаж и пряжа остаются в существующей [библиотеке персонажей](../../Characters/Materials/Substance). Иллюстрации к постановкам, подписи, швы по конкретной форме и маски слотов остаются в SPP ассета.

Экспорт `Stage Shift Unreal ORM.json` основан на Unreal Engine (Packed) из Painter. Передайте конфигурацию в `substance_painter.export.export_project_textures` с путём назначения и массивом Texture Set в `exportList`. Папка [Showcase](../Showcase) содержит проверочный SPP, экспорты и кадры с двумя типами освещения. [Руководство проекта](../../../Docs/ArtDirection.md) описывает выбор материалов и проверку в игре.
